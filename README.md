# QR Expense Tracker

Ứng dụng Flutter theo dõi chi tiêu cá nhân bằng Supabase. Tài khoản đăng nhập
bằng email/mật khẩu; mỗi người chỉ truy cập được giao dịch của chính mình.
VietQR được phân tích cục bộ theo cấu trúc EMVCo; ảnh biên lai được nhận dạng
bằng ML Kit trên thiết bị. Ảnh bill vẫn lưu cục bộ, không tải lên Supabase.
Quét ảnh giao dịch cần chạy trên Android hoặc iOS; Chrome chỉ hỗ trợ quét VietQR.

## Cấu hình Supabase

1. Tạo project Supabase, bật Email trong Authentication > Sign In / Providers.
   Để đăng ký xong đăng nhập được ngay mà không cần xác nhận email, mở phần
   Email và tắt **Confirm email**. Khi bật tùy chọn này, Supabase yêu cầu xác
   nhận email trước khi tạo phiên đăng nhập.
2. Trong SQL Editor, chạy lệnh sau để tạo bảng và bật Row Level Security:

```sql
create table public.expenses (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  merchant text not null,
  total_amount double precision not null check (total_amount > 0),
  date timestamptz not null,
  category text not null,
  image_path text,
  transaction_code text,
  qr_content text
);

alter table public.expenses enable row level security;

create policy "Users can manage their own expenses"
on public.expenses
for all
to authenticated
using ((select auth.uid()) = user_id)
with check ((select auth.uid()) = user_id);
```

3. Lấy Project URL và publishable key (hoặc anon key) trong phần API của
   Supabase. Không dùng `service_role` key trong ứng dụng.
4. Truyền thông tin cấu hình lúc chạy/build:

```sh
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_OR_ANON_KEY
```

## Chạy ứng dụng

Yêu cầu Flutter stable, Dart SDK theo `pubspec.yaml` và thiết bị Android hoặc
iOS. Từ thư mục dự án:

```sh
flutter pub get
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_OR_ANON_KEY
```

## Build APK Android

Cần cài Android SDK, Android SDK Command-line Tools, Android SDK Platform và
NDK phiên bản được Flutter yêu cầu. Chấp nhận Android licenses rồi chạy:

```sh
flutter doctor --android-licenses
flutter build apk --release --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_OR_ANON_KEY
```

APK được tạo tại `build/app/outputs/flutter-apk/app-release.apk`.

Nếu build báo NDK thiếu `source.properties`, cài lại phiên bản NDK được báo
trong lỗi bằng Android Studio > SDK Manager > SDK Tools > NDK (Side by side);
không tự tạo file `source.properties`. Nếu build báo Gradle lock đang được
tiến trình khác giữ, chờ build đó kết thúc trước khi chạy lại.

## Tính năng

- Chụp ảnh hoặc chọn ảnh giao dịch thanh toán, tự nhận diện số tiền, ngày, mã
  và nội dung giao dịch trên thiết bị; có thể chỉnh lại và chọn loại chi tiêu
  trước khi lưu.
- Đăng ký/đăng nhập và lưu, sửa, xóa giao dịch trên Supabase với quyền truy
  cập được giới hạn theo tài khoản.
- Giao dịch được lưu tạm cục bộ khi ngoại tuyến và tự đồng bộ lại khi kết nối
  trở lại.
- Dashboard tổng chi, donut chart theo danh mục, biểu đồ 7 ngày và lịch sử.
